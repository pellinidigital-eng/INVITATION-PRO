# Invitation Creator PRO

Premium mobile-first web app for animated digital invitations.

## Stack

- Next.js App Router
- Tailwind CSS
- Framer Motion
- Local smart-copy engine, no AI APIs and no paid external keys
- Browser export for PNG, PDF and QR code

## Run

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Main Routes

- `/` studio, dashboard, live preview and export
- `/invite/mario-giulia` shareable invitation page
